# Projeto Futebol

## Sobre o projeto

Este projeto foi desenvolvido como uma questão da prova da disciplina de Desenvolvimento Front-End para Web.

O tema escolhido foi o futebol, apresentando informações sobre sua origem, sua história e algumas de suas principais competições.

## Páginas

O projeto possui três páginas principais:

* **index.html** — apresenta uma introdução ao futebol e informações sobre a origem do futebol moderno.
* **historia.html** — apresenta informações sobre a história e a evolução do futebol.
* **competicoes.html** — apresenta informações sobre algumas competições de futebol, além de uma tabela e um formulário.

## Estrutura do projeto

As páginas HTML estão organizadas na pasta `html/`.

A pasta `img/` é destinada às imagens utilizadas no projeto.

A pasta `audio/` é destinada aos arquivos de áudio.

A pasta `video/` contém o arquivo de vídeo utilizado no projeto.

## Recursos utilizados

Durante o desenvolvimento foram utilizados recursos de HTML5, incluindo:

* Estrutura semântica com `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`;
* Tabelas;
* Formulários;
* Imagens e vídeos;
* `figure` e `figcaption`;
* `details` e `summary`;
* Elementos de marcação de texto;
* Navegação entre páginas.

## Objetivo

O objetivo do projeto é demonstrar os conhecimentos adquiridos durante as aulas de HTML e desenvolver um site simples, organizado e útil sobre o tema escolhido.
